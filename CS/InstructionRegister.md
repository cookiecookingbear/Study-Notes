# Instruction Register

- IR이라고도 하며, 현재 CPU가 실행하려는 명령어를 저장하는 레지스터다.

- 우리가 프로그램 하나를 실행하면, CPU에서는 Load, Add, Store등의 명령어들을 실행한다.
- 이 때, 이 명령어들을 실행하기 위한 명령어 사이클이 생긴다.

	> 명령어 사이클 :
	>> 명령어 가져오기(Fetch) - 명령어 해석(Decode) - 명령어 실행(Execute) - 다음 명령어 등의 실행 과정

- CPU는 이런 명령어들을 바로 실행하는 것이 아니라, 메모리 내 특정 주소에 명령어들을 저장해두고, 명령어의 주소를 통해 명령어에 접근한다.

- 이렇게 ==가져온 명령어(=현재 실행중인 명령어)를 저장하는 장소==를 Instruction Register라고 한다.

## PC(Program Counter)과의 차이점

- PC의 경우 다음 수행할 명령의 ==주소==를 저장한다
- IR의 경우 수행할 명령 자체를 저장한다.
