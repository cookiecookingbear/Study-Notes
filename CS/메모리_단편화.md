# 메모리 단편화(Memory Fragmentation)

- 메모리 공간이 조각나서, 전체 여유 공간은 충분해도 실제로는 원하는 크기의 메모리를 할당하지 못하거나 일부 공간이 낭비되는 현상

- 크게 [외부 단편화](./CS/메모리_단편화_외부.md)와 [내부 단편화](./CS/메모리_단편화_내부.md)가 있다.

- 게임개발 관점에서는 운영체제 단계에서의 메모리 단편화보다, Heap Fragmentation을 더 자주 언급한다.

	> Heap Fragmentation이란, 메모리 할당과 해제가 자주 일어나면 나타나는 현상
	>> 적 개체 Instantiate후 Destroy반복

	- 메모리 할당과 해제가 자주 일어나면 Heap공간이 조각난다.

	- 이를 해결하기 위해 게임에서는 Object Pooling을 사용한다.
