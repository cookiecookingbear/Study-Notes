# 메모리 외부 단편화

- 메모리의 빈 공간들이 여러 곳에 흩어져 있어서, 총 빈 공간은 충분하지만 연속된 큰 공간을 확보하지 못하는 현상

### 원인

- 가변 크기 할당

	1. 연속 메모리 할당
	1. 세그먼테이션
	1. Heap 동적 할당


### 해결

- Paging

	- 프로세스가 물리 메모리에 연속적으로 할당될 필요가 없다. 빈 공간이 있으면 집어넣기만 하면 된다.

- [압축(Compaction)](./CS/메모리_단편화_압축)

	- 흩어진 사용 영역을 한쪽으로 모아서 큰 연속된 빈 공간을 만든다.

	- 단점

    	> 메모리 이동 비용이 크다.\
		> 실행 중인 프로세스의 주소 재배치가 필요하다.

- 적절한 블록 크기 선택

	- 블록 크기가 너무 크면 낭비가 커진다.

	- 그렇다고 해서 블록 크기가 너무 작으면 관리 오버헤드가 커진다.
