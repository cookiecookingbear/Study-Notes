# CPU와 GPU
- CPU
    > 복잡한 작업을 빠르고 유연하게 처리한다.\
    > 비교적 코어 수가 적다.(4,8,16 등의 pc용, 서버용으로는 더 많을 수 있다.)\
    > 지연시간이 짧다.\
    > 캐시가 크다.
    >> 복잡한 계산이 많고, 메모리에 불규칙적으로 접근하기 때문이다.
- GPU는 단순한 작업을 대량으로 동시에 처리한다.
    > 단순한 작업을 대량으로 동시에 처리한다.\
    > 본래 그래픽 처리를 위해 개발되었다.\
    > 코어 수가 많다.(수천개 정도)
    > AI의 행렬 연산에 적합하여 AI 연산에 많이 사용된다.\
