# 메모리 인터리빙(Memory Interleaving)

- 주기억장치를 여러 개의 메모리 뱅크로 나누고, 연속된 주소를 서로 다른 뱅크에 분산 저장하여 메모리 접근 성능을 높이는 기법
- CPU가 메모리를 기다리는 시간을 줄이는 것이 핵심

### 등장 배경

- CPU와 RAM의 속도 차이

	- 보통 CPU의 속도가 RAM을 읽는 속도보다 빠르다.

### 기본 구조

1. 메모리를 여러 개의 독립적인 뱅크로 나눈다.

1. 연속되는 주소를 다른 뱅크에 분산 저장한다.

- 이렇게 하면 연속되는 물리 주소의 메모리에 접근할 때, 서로 다른 뱅크를 사용하면서 읽기 속도를 높일 수 있다.

### 종류

1. Low-Order Interleaving

	- 주소의 하위 비트로 뱅크를 선택
	
		- 예를 들어, 4개의 뱅크(0,1,2,3)를 사용할 때, 각 주소의 마지막 두 비트에 따라(00, 01, 10, 11) 뱅크 선택

1. High-Order Interleaving

	- 주소의 상위 비트로 뱅크 선택

    	- 큰 주소의 영역 단위로 나뉘기 때문에, 순차 접근의 측면에서는 효과가 낮다.


### 멀티채널 메모리

- 현대 PC에서는 Dual 혹은 Quad 채널의 RAM 슬롯을 지원하는데, 이 방식이 인터리빙의 동작 방식과 유사하다.

### 장점

1. 메모리 대역폭 증가
1. CPU 대기시간 감소
1. 순차 접근 성능 향상

### 단점

1. 하드웨어가 복잡해짐
1. 충돌 가능성

    - 만약 Low-Order Interleaving을 사용하는데, 주소의 끝이 0, 4, 8, 12처럼 끝난다면 모두 하나의 뱅크에 저장되어 인터리빙의 의미가 옅어질 수 있다.
    - 이 경우를 ==Bank Conflict==라고 한다.
