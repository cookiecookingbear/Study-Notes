# 가상메모리 세그먼테이션

- 프로그램을 논리적 단위(Segment)로 나누어 메모리를 관리하는 기법
- Paging과는 다른 메모리 관리 기법 중 하나

### Paging과의 차이점

#### 영역 구분

- Paging은 각 페이지를 고정 크기로 나눈다.

    > 크기만을 기준으로 영역을 나누기 때문에, 나눠진 영역이 무슨 코드인지 알 수 없음.

- Segmentation은 메모리 영역을 의미 있는 단위로 나눈다.
    
    1. 코드 영역
    1. 데이터 영역
    1. 스택 영역
    1. 힙 영역

#### 주소 구조

- Paging은 `Page No.` + `Offset`구조
- Segmentation은 `Segment No.` + `Offset`구조

    - Segment Table도 있고, Page Table과 유사하기도 하다.
    - 다만,  Segment Table은 `Base`와 `Limit`정보를 담는다.

        > `Base`는 몇번 주소부터, `Limit`은 어디까지 해당 영역(=영역 크기)인지 구분한다.

### 장점

1. 보호

    > 각 영역별로 읽기, 쓰기 권한 부여가 가능하다.

1. 공유

    > 여러 프로세스가 같은 영역 사용 가능

### 단점

1. 외부 단편화

    > 세그먼트 크기가 가변적이기 때문
