# 메모리 내부 단편화

- 할당받은 메모리 블록 내부에서 실제로 사용하지 않는 공간이 낭비되는 현상
	
	> 예를 들어, 메모리를 4KB단위로만 할당한다고 할 때, 6KB짜리 프로세스를 위해 8KB를 할당하고 나머지 2KB가 낭비되는 상황

- 문제점은 **빈 공간이 존재하지만, 재사용할 수 없다**는 점이다.

### 원인

- 고정 크기 할당

	1. Paging
	1. [메모리 풀](./CS/메모리_단편화_메모리풀.md)

### 해결

- 할당 크기 조절

	- 할당하는 크기가 커지면, Page Table이 작아지고 TLB 효율이 증가하지만 내부 단편화가 증가한다.
	- 할당하는 크기가 작아지면, 내부 단편화는 감소할 수 있으나 Page Table이 과도하게 커진다.

### 취급

- 보통 외부 단편화보다 덜 심각하게 취급된다.

	- 외부 단편화는 할당 자체를 실패할 수 있음.
	- 내부 단편화는 할당은 성공했지만, 효율의 문제가 있음.
