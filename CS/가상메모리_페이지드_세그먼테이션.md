# 가상메모리 페이지드 세그먼테이션

- Paging과 Segmentation의 장점을 모두 사용하기 위해 나온 방식

- 기본적으로 Segment로 나눈 뒤 Paging을 적용한다

- 따라서 주소의 구조는 `Segment No.` + `Page No.` + `Offset`으로 이루어져 있다.


### 장점

- 외부 단편화 해결

	- Segmentation의 외부 단편화는 **세그먼트 크기가 가변**이라는 점 때문에 발생

- Segmentation 장점 유지

	- 논리적 구조 유지
	- 보호 유지
	- 프로세스간 공유 가능

### 단점

- 주소 변환이 복잡해진다.

- 테이블 크기 증가

- 구현 난이도 증가
