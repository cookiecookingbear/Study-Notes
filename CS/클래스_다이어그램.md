# 클래스 다이어그램

## 객체지향 시스템의 클래스 구조와 클래스 간 관계를 그림으로 표현한 [UML 다이어그램](./UML다이어그램.md)

- 프로젝트의 규모가 커지면 클래스의 수가 많아지고, 클래스 간의 관계도 복잡해지므로 클래스 다이어그램을 통해 시스템의 구조를 시각적으로 표현하여 이해하기 쉽게 만든다.
    > 어떤 클래스가 있고, \
    누가 누구를 참조하며\
    누가 누구를 상속하는지.

- 기본 구조
    1. 클래스 이름
    
    2. 속성(Attribute)
    
        > 멤버 변수

    3. 메서드(Operation)
   
        > 멤버 함수

    4. 접근 지정자 표시
        >|기호|의미|
    |---|---|
    |+|public|
    |-|private|
    |#|protected|
    |~|package(default)|
        >> 예시) +Move() : public void Move()

    5. 상속 관계
    
        > 상속 관계는 일반적으로 실선과 찬 화살표로 표시하며, 화살표의 방향은 자식 클래스에서 부모 클래스로 향한다.
        >> class A{}\
        class B : A\
        Bㅡ▶A

    6. 연관 관계

        > 실선으로 나타내며, 객체나 클래스가 어떤 객체를 참조했는지 나타낸다.

    7. 집합 관계

        > 가지고는 있지만 독립적으로 존재 가능한 관계로 실선과 빈 마름모로 표현한다.

    8. 합성 관계

        > 강하게 소유하는 관계. 실선과 채워진 마름모로 표현한다.\
        > 소유되는 쪽에서 소유한 쪽을 향한다.

    9. 의존 관계

        > 일시적으로 참조하여 사용하는 관계. 참조하는 쪽이 참조되는 쪽을 변수로 갖지는 않고, 단지 사용만 하는 경우
        > 점선과 열린 화살표로 표현하고 사용한 쪽에서 참조되는 쪽을 향한다
