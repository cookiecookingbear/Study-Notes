# ALU (Arithmetic Logic Unit)

- 산술 연산(Arithmetic)과 논리 연산을 수행하는 CPU 내부의 연산 장치

- CPU를 단순화하면

	1.제어장치\
	2.ALU\
	3.레지스터
	
	로 분류할 수 있는데 이는 각각 지휘관, 계산기, 메모장 정도에 비유할 수 있다.

- 제어장치는 무슨 작업을 할지 결정한다.
- ALU는 실제 계산을 수행한다.

    > 구체적으로는 산술, 논리, 비교, 비트 연산을 담당한다.\
	> 과거에는 실수 계산을 담당하던 FPU(Floating Point Unit)이 별도로 있었으나, 지금은 통합되었다.

- 레지스터는 계산에 사용할 데이터를 저장한다.
