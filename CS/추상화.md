# 추상화(Abstraction)
- ==복잡한 내부 구현은 숨기고==, 중요한 개념과 기능만 드러내는 것
    > 어떻게 동작하는가, 보다는 무엇을 하는가에 집중하게 만드는 기술
- 예를 들어,
    >```csharp
    >player.Move();
    >```
    가 있다고 할 때, 호출하는 쪽에서는 물리 계산, 애니메이션 처리, 입력 처리 등의 상세 구현을 몰라도 된다.
- 만약 추상화가 없다면 모든 코드가 내부 구현을 전부 알아야 하는 상태가 만들어지고 유지보수 난이도가 올라가고 결합도가 증가한다.
- 따라서 추상화는
    >```
    >복잡성 감소
    >결합도 감소
    >사용성 향상
    >유지보수성 향상
    을 목표로 한다.
