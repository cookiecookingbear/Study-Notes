# 다형성 Polymorphism
- 같은 인터페이스(호출 방식)로 서로 다른 동작을 수행할 수 있는 성질.
- 객체 지향 프로그래밍의 SOLID 원칙 중 OCP(Open-Closed Principle)와 LSP(Liskov Substitution Principle)를 구현하는 데 중요한 역할을 한다.)
- 유지보수성, 확장성, 의존성 분리, 구조 유연성을 위해 필수적으로 사용하는 개념이다.
- 오버로딩
    > 같은 이름의 메서드지만, 매개변수의 타입이나 개수가 다르거나, 반환 타입이 다르다.\
    > 이 때, 어떤 메서드를 호출할지는 컴파일러가 컴파일 시점에 결정한다.\
    > 정적 다형성이라고도 한다.
- 오버라이딩
    > 부모 클래스의 메서드를 자식 클래스에서 재정의하여 사용하는 것.\
    > 실제 객체 기준으로 어떤 메서드를 호출할지 결정한다.\
    > 동적 바인딩(런타임 다형성)이라고도 한다.\
    > 부모 클래스에서는 virtual 키워드를 사용하여 메서드를 선언하고, 자식 클래스에서는 override 키워드를 사용하여 재정의한다. 이 때, 자식 클래스에서 virtual 키워드가 적용된 메서드를 반드시 재정의해야 한다.\
    > virtual 메서드가 하나라도 있는 클래스를 추상 클래스라고 한다.
- 서브타입 다형성
    > 부모 타입으로 자식 객체 사용
